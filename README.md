# carousel

An infinite, scroll-driven image carousel built with React, TypeScript and Tailwind.

What I'm focusing on:

- **Clean architecture:** the carousel is decoupled from the data source, so it stays reusable.
- **Performance:** it should feel the same with 12 images or 1,000+.
- **Smooth UX:** native scrolling on desktop and mobile, and it handles any image size or aspect ratio.

## Run

```sh
npm install
npm run dev
```
